# Ручная проверка P-Treasury на вашем компьютере

Автоматические тесты проверяют приложение на Linux. Этот список проверяет то, что видно только на вашем Windows: установку, трей, уведомления и обычную работу. Займёт около 40 минут. Отметьте каждый пункт и запишите замечания, даже мелкие («кнопка неудобно стоит», «шрифт мелкий»).

| № | Что сделать | Что должно получиться | ✓ | Замечания |
|---|---|---|---|---|
| 1 | Запустить установщик `P-Treasury_…_x64-setup.exe` | Установка без прав администратора, в меню «Пуск» появляется P-Treasury со значком «Дверца сейфа» | | |

| 4 | Ctrl+N, расход 350 ₽, получатель «Пятёрочка», категория «Продукты» | Операция в списке, баланс карты меньше на 350 ₽ | | |
