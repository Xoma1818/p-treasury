## Улучшения по решению владельца

Ревью нашло три места, где меняется то, что видит пользователь, или сборка выпуска. Владелец 22.10.2026 выбрал сделать все три:

1. Цель с очень маленьким темпом показывала прогноз через тысячи лет (или «нет пополнений»). Теперь — «При нынешнем темпе — больше 100 лет», а при сроке цель помечается «Не успеваете» (тест в `goals.rs`).
2. Выписка, для банка которой ещё не выбран счёт, в импорте из папки запоминалась как «не выбран счёт» и больше не бралась. Теперь при каждой проверке она ждёт молча и загружается, как только счёт выбран (тест в `auto_import.rs`).
3. Выпуск собирается с оптимизацией всей программы (`lto`, `codegen-units = 1`) и без отладочных символов (`strip`). Паника остаётся раскруткой, чтобы сбой одного действия не останавливал остальные.

## Как повторить

```bash
scripts/check.sh --e2e
PTREASURY_VOLUME_DIR=папка cargo test --release -p budget-core --test volume -- --ignored --nocapture
PTREASURY_VOLUME_DIR=папка node --test e2e/volume.test.mjs
PTREASURY_OLD_BIN=путь/к/сборке/0.11.1 node --test e2e/upgrade.test.mjs
```

Как собрать старую версию для теста обновления, написано в [разработке](../development.md).
