## Второй круг: какие действия реально проходят тесты (вопрос OTTO «ты точно уверен?»)

Обход кнопок ловит только ошибки и «ничего не случилось», но не неверный результат. Поэтому полный прогон
сквозных тестов повторён с записью, какие команды ядра они вызывают (временная правка `lib.rs`, в PR не входит).

- До: 52 команды из 227 не вызывал ни один сквозной тест, из них 44 — за кнопками интерфейса: правка и закрытие
  счёта, правка и архив категории, правка и удаление цели, заметки, напоминания (отложить, выполнить, вернуть,
  выключить, удалить), курсы, бюджет (заметка, удаление), «Месяц завершён» / «Открыть снова», массовые правки
  операций (счёт, получатель, тег), теги, шаблоны, события, имущество, сценарии, кредитные каникулы и смена ставки,
  название долга.
- Добавлен [e2e/edits.test.mjs](../../e2e/edits.test.mjs): 17 сценариев, каждый проверяет итог на экране
  (баланс, название, список, ближайший платёж).
- После: без сквозного теста осталось 20 команд. 10 из них интерфейс не вызывает вовсе (`calc_loan`,
  `compare_loans`, `dismiss_reminder`, `pay_reminder`, `get_transaction`, `inspect_backup`, `rate_on`,
  `set_transaction_spread`, `set_transaction_tags`, `update_transaction` — старые входы, интерфейс ходит
  через другие команды). 2 нельзя проверить в облаке (`install_update`, `open_folder`). Остальные 8 —
  редкие: чек (удаление разбивки), инвест-план месяца и стоимость инвестсчёта, «Не моя» в совпадениях
  импорта, массовое переименование категорий, «это и следующие» у напоминания, журнал «Что нового».

## Что в облаке проверить нельзя

Системные окна выбора файла (тесты подставляют путь), уведомления Windows о напоминаниях, «Открыть папку» в Проводнике,
горячая клавиша быстрого ввода вне окна. Это пункты для ручной проверки в [owner-checklist.md](owner-checklist.md).

## Как повторить обход

```bash
npx vite build && cargo build -p budget-app --features custom-protocol
xvfb-run -a node e2e/crawl.mjs   # итог: kazna-crawl-*/findings.json во временной папке
```

Записи `noop` у уже выбранной вкладки («Этот месяц», «Месяц», «Расходы») — не ошибка: она и так открыта.
