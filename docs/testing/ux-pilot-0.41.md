# Казна 0.41. Повторная встреча через неделю

Сможет ли человек через семь дней самостоятельно повторить две задачи и до подтверждения предсказать, что произойдёт с деньгами? Встречи ещё не проводились. Предыдущие задания собраны в [протоколе 0.39](ux-pilot-0.39.md).

## До встречи

Для Windows подготовлен переносной учебный набор Kazna 0.41. Распакуйте весь архив в папку с доступом на запись. Дайте участнику [карточку заданий](pilot-0.41/participant.html), себе откройте [лист наблюдений](pilot-0.41/moderator.html).

1. Дважды нажмите «Начать.cmd». Клавиша **1** открывает задание про аренду, **2** — про бюджет. Каждый запуск создаёт отдельный бюджет в папке `visits` рядом с программой. Даты задаются по часам компьютера в день визита.
2. Для аренды также откроется Проводник с выделенным файлом «аренда.csv». Передайте его участнику после того, как он создаст расписание. Между заданиями закройте учебное окно и запустите «Начать.cmd» снова.
3. Через неделю повторите запуск для того же кода участника. Сверяйте результаты визитов по двум листам наблюдений. Если заполняете их в браузере, распечатайте или сохраните в PDF до закрытия вкладки.

Пригласите одних и тех же участников на обе встречи. Присвойте каждому код, например У01. Запишите сборку, размер окна и даты обеих встреч. В наблюдениях используйте этот код и учебные суммы. Начинайте оба задания с «Главной».

**Исходные данные для сверки**

- **Аренда.** Счёт «Карта» открыт 60 дней назад с 40 000 ₽. В журнале один расход «Аренда» на 10 000 ₽ 28 дней назад. Расписание пусто. В файле «аренда.csv» одно сегодняшнее списание 10 000 ₽.
- **Бюджет.** В текущем месяце фиксированные лимиты составляют 3 000 ₽ на «Питание» и 2 000 ₽ на «Досуг». С карты списаны 3 400 ₽ за продукты, наличными — 1 000 ₽ за музей. До покупок остатки составляли 26 000 ₽ и 6 000 ₽ соответственно. [Оконный тест обоих заданий](../../e2e/repeat-and-cover.test.mjs).

## Карточка участника на обе встречи

1. Прошлая оплата аренды уже есть в журнале. По ней запланируйте аренду каждый месяц, ближайший срок — завтра. Затем возьмите у ведущего учебную выписку. Банк списал деньги сегодня, на день раньше срока. Загрузите выписку и отметьте в календаре, какой платёж прошёл. Перед каждым из трёх подтверждений скажите, сколько записей об оплате окажется в журнале и сколько денег будет на карте.
2. На питание потрачено на 400 ₽ больше плана. Используйте свободную часть бюджета на досуг, чтобы покрыть разницу. Перед подтверждением назовите будущие лимиты обеих категорий, общий план, фактические расходы и остатки на обоих счетах.

## Лист ведущего

Показывайте только карточку. Отсчитывайте время от чтения задачи до результата или остановки. Перед каждой кнопкой запишите первый ответ дословно. Если участник просит помочь, сначала отметьте, где он остановился, затем запишите подсказку. На второй встрече дайте те же задания без напоминания о первом прохождении.

| Когда сверять | Ожидаемый результат |
|---|---|
| После создания расписания | Один ежемесячный повтор с завтрашней даты. В журнале одна операция, на карте 30 000 ₽. |
| После импорта → после связи | Сначала две операции и 20 000 ₽. После связи те же две операции и 20 000 ₽. Откройте платёж из календаря и сверьте сегодняшнюю дату. |
| После покрытия перерасхода | Питание 3 400 ₽, досуг 1 600 ₽. План 5 000 ₽, факт 4 400 ₽. На карте 22 600 ₽, наличными 5 000 ₽. |

| Код, дата, визит, задача | Прогнозы и их точность | Факт на экране | Время | Где остановился, какая помощь понадобилась |
|---|---|---|---|---|
| | | | | |

Заполняйте по строке на задачу и визит. Сопоставьте попытки одного человека. Для каждого визита отметьте, кто достиг результата самостоятельно и верно предсказал суммы до подтверждения. Время сравнивайте только для завершённых задач. Пропущенный визит отметьте отдельно.

## Сборка набора для ведущего

В корне архива лежат [Начать.cmd](pilot-0.41/start.cmd), карточка «Задания.html» и «Лист ведущего.html». В папку `app` положите `Kazna.exe` и маркер `portable` из [проверенной сборки Windows x64](https://github.com/Xoma1818/p-treasury/actions/runs/45082106249), а также `prepare_ux_pilot.exe`. Последний собирается в Windows командой `cargo build -p budget-core --release --locked --example prepare_ux_pilot` из [исходного файла генератора](../../crates/core/examples/prepare_ux_pilot.rs).
