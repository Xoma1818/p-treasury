## Что проверяли

Приложение Tauri собиралось со встроенным интерфейсом. EdgeDriver управлял одним настоящим окном Kazna на отдельном рабочем столе Windows 11. Временный профиль WebView2, папка данных и резервные копии создавались отдельно для каждого прогона. Набор данных создавался кнопкой «Посмотреть на примере» в самой программе.

Итоговый сквозной маршрут прошёл 24 из 24 проверок. Окно загрузило `index-Ly4x8Aun.css`. При обычном движении отметка меню переместилась за 185 мс, при уменьшенном сразу появилась у выбранного раздела. В системном контрасте выбранная дата получила рамку 2 px. График активов размером 84 × 26 px открыл историю активов.

## Замечания, исправленные до передачи

- В контрастных схемах Windows включённый переключатель обновлений мог сливаться с фоном. В Edge проверены четыре сочетания темы Kazna и системной контрастной схемы. Ползунок использует системную пару цветов.
- Динамика общего баланса и динамика чистых активов визуально конкурировали на Главной. Мини-график активов перемещён к его собственной сумме. Кнопка открывает историю активов.

Исполняемый файл итоговой сборки Windows x64 имеет SHA-256 `606a6d1cb7dbab7440205a4c56d770a0849a51c9e6b7f0965394cc8bf6cedcf3`. Пробная переносная копия содержит файл `portable` и хранит учебный бюджет в своей папке `data`.
