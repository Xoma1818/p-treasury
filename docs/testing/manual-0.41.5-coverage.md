## Границы заключительного прохода

- Штатный выход завершил проверенный процесс. В копии из 121 операции — одна контрольная покупка на 7,89 ₽. Эти данные сверены непосредственно в файлах. Отображение покупки при следующем запуске остаётся открытым.
- Для чистой установки и штатного обновления с предыдущего выпуска требуется выделенная среда. Там же остаются испытания отказа подписи/загрузки, недоступного стартового пути, полного диска и аварийного завершения. В имеющемся окне проверены отказ записи в занятую копию и безопасный повтор.
- Для системных действий остаются меню трея и отдельное окно быстрого ввода с глобальной клавишей, реальная доставка уведомлений, суточная проверка курса. Положительный XML-ответ ЦБ был локальным. Фоновый импорт и создание копии при выходе подтверждены.
- Для денег остаются независимая сверка обычного факта категории после привязки к событию, ввод несовпадающей суммы при привязке календарного платежа, изменение ставки с даты и перепроверка найденных ошибок на исправленной сборке. Полный список открытых критериев дан по ID ниже.
