## Нагрузка и глубина проверки

Учебный журнал содержит 116 960 проводок за 731 день с 1 января 2024 по 31 декабря 2025 года, по 160 проводок в день. Корпус включает реальные по структуре записи доходов, расходов и межвалютных переводов. Для каждого дня проверены два итога календаря. Для каждого из 24 месяцев проверены доходы, расходы, сальдо, фактические итоги бюджета, оба остатка и детализация баланса.

В этом же окружении выполнены 470 существующих тестов ядра и регрессий, включая смену начала месяца на 1-е, 25-е и 31-е, импорт повторяющейся и перекрывающей выписки, отмену и повтор операции, выход через CSV/XLSX/OFX, досрочное погашение, поиск и собственные показатели Главной. Число тестов указано отдельно от количества записанных пар «ожидание / факт».

Кнопки, изменение экранов, системные шрифты и ярлыки проверяются в отдельных Windows-прогонах. Числовой набор запускается на Ubuntu 24.04, использует новые базы SQLite в памяти; выборки не исчерпывают все сочетания дат, правил, данных, действий и устройств.

При отладке эталона отдельные запланированные проводки были ошибочно приняты за календарный план. Подпись экрана определяет источники этого показателя как платежи по долгам и напоминания с суммой. Для дифференцированного кредита исправлено ожидаемое деление тела на три части — до минимальной единицы с поправкой в последней строке. В контрольной фикстуре разные суммы для календаря и для свободных денег, чтобы различить эти источники.
