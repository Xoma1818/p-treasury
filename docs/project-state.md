- 21.11.2026 подготовлен кандидат `0.37.1` в `codex/prevent-double-accounting`. Спорные банковские строки разбираются до записи. Календарь проверяет проведённые платежи перед созданием и повторяет проверку при сохранении. Операция и завершение напоминания сохраняются вместе. При повторном импорте записи сопоставляются по исходному получателю, если он известен. Выписку, которая только подтверждает ручные операции, можно сохранить кнопкой «Связать».

Пакетный предпросмотр нескольких выписок, массовый разбор и вложения чеков остаются отдельными идеями. В выпущенной Kazna на вымышленных данных воспроизведены временный двойной учёт при спорном импорте и повторный платёж после выбора «Создать операцию» у напоминания с найденным совпадением. Входы с Главной и из Операций используют одну очередь. Число операций без категории повторяется в двух блоках интерфейса.
