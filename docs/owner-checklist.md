# Ручная проверка «Казны» на вашем компьютере

Автоматические тесты проверяют приложение на Linux. Этот список проверяет то, что видно только на вашем Windows: установку, трей, уведомления и обычную работу. Займёт около получаса. Отметьте каждый пункт и запишите замечания, даже мелкие («кнопка неудобно стоит», «шрифт мелкий»).

| № | Что сделать | Что должно получиться | ✓ | Замечания |
|---|---|---|---|---|
| 1 | Запустить установщик `Казна_…_x64-setup.exe` | Установка без прав администратора, в меню «Пуск» появляется «Казна» со значком-кольцом | | |
| 2 | Открыть «Казну» | Мастер первого запуска: валюта, счета, категории | | |
| 3 | Пройти мастер: рубли, «Карта» с текущим остатком, «Наличные» | На Главной общий баланс равен сумме остатков | | |
| 4 | Ctrl+N, расход 350 ₽, получатель «Пятёрочка», категория «Продукты» | Операция в списке, баланс карты меньше на 350 ₽ | | |
| 5 | Снова Ctrl+N, начать вводить «Пят…» | Подсказывается «Пятёрочка» и сама ставится категория «Продукты» | | |
| 6 | В поле суммы набрать `1890+455`, сохранить | Сохраняется 2 345 ₽ | | |
| 7 | Ctrl+T: перевод 5 000 ₽ с карты на наличные | Балансы обоих счетов изменились, в расходах перевода нет | | |
| 8 | Удалить последнюю операцию, нажать Ctrl+Z | Операция вернулась | | |
| 9 | «Бюджет»: создать бюджет месяца, лимит «Продукты» 15 000 ₽ | Видно потрачено, остаток и «Можно тратить сегодня» | | |
| 10 | «Долги» → «Калькулятор»: 300 000 ₽, 18 %, 24 мес. | Платёж 14 977,23 ₽; «Сохранить как долг» создаёт кредит | | |
| 11 | «Напоминания»: «Проверка» на сегодня через 2 минуты, свернуть окно | Через 2 минуты приходит уведомление Windows | | |
| 12 | Закрыть окно крестиком | Приложение уходит в трей (значок у часов), из трея открывается снова | | |
| 13 | «Отчёты»: посмотреть месяц, нажать «Выгрузить» | Файл Excel открывается, суммы числами | | |
| 14 | «Настройки» → «Данные» → «Сводка в Excel» за месяц | 6 листов, итоги совпадают с отчётом | | |
| 15 | «Настройки» → «Резервная копия» → «Сделать копию» на флешку или в папку | Файл копии появился, время последней копии обновилось | | |
| 16 | Добавить ещё одну операцию, затем «Восстановить» из копии шага 15 | Операция из шага 16 исчезла, остальное на месте; прежние данные сохранены отдельной копией | | |
| 17 | Кнопка «Скрыть суммы» (или Ctrl+H) | Суммы скрыты на всех экранах, Ctrl+H возвращает | | |
| 18 | Выйти из приложения через трей и открыть снова | Все данные на месте, пропущенные напоминания показаны окном | | |
| 19 | «Отчёты» → «Сравнение», пара «Месяц к прошлому» | Видно, какие категории выросли и какие уменьшились, в рублях и в %; клик по категории открывает её операции | | |
| 20 | Когда выйдет следующая версия: «Настройки» → «Обновления» → «Проверить» | Окно «Доступна версия …», после установки данные на месте | | |
