## В1. Прогноз остатка на 12 месяцев

Месяцы бюджетные (настройка «первый день месяца»), первый — текущий, с сегодняшнего дня.

| Что | Откуда |
|---|---|
| Старт | Деньги на наличных, картах и вкладах «в общем балансе» сегодня — как у финансовой подушки |
| По датам | Невыполненные напоминания с суммой (расход или доход), невыплаченные строки графиков займов (по взятым — минус, по выданным — плюс), запланированные операции. Валюта займов и операций — по курсу на сегодня |
| Обычные доходы и траты | Среднее по категориям за последние 3 полных месяца (не раньше начала учёта). Не входят: операции займов (`debt_id`), поездки и события, операции, отмеченные по напоминанию, категории повторяющихся напоминаний с суммой — они уже посчитаны по датам. Траты на несколько месяцев — по частям |
| Текущий месяц | По каждой категории «среднее минус уже случилось», не меньше нуля |

На экране: «Сейчас», «Через 12 месяцев», «Самый низкий остаток», «Хватит на N мес.» (деньги / обычные траты), предупреждение о первом месяце с минусом, график остатка на конец месяца, таблица по месяцам с раскрытием и блок «Как считается».

*Сценарий:* карта 100 000 ₽, три месяца зарплата 80 000 и траты 42 000 → каждый месяц +38 000 ₽; напоминание «Аренда 25 000 ₽» с категорией «Жильё» убирает аренду из среднего и ставит её 1-го числа каждого месяца.

## В2. «Что если»

Сценарий — название и до 50 изменений. Хранится в `forecast_scenarios` / `forecast_changes`, на операции не влияет; создание, правка и удаление отменяются Ctrl+Z.

| Изменение | Действие |
|---|---|
| Разовая сумма | ± сумма в выбранном месяце |
| Каждый месяц | ± сумма с месяца на N месяцев (пусто — до конца прогноза) |
| Доходы в % | Все доходы месяца (обычные и по датам) меняются на −100…+1000 % |
| Обычные траты в % | Обычные траты месяца (не платежи по датам) меняются на −100…+1000 % |

Заготовки: «Ипотека или кредит», «Крупная покупка», «3 месяца без зарплаты», «Прибавка 10 %», «Тратить на 15 % меньше». Выбранный сценарий рисуется пунктиром, в таблице — своя колонка, плитки и предупреждение считаются по нему.

## В4. Поток денег

За месяц или год. Слева доходы по категориям верхнего уровня, справа расходы, «Инвестиции» (переводы с быстрых счетов на брокерские минус выведенное) и «Осталось». Если потрачено больше, слева «Из накоплений» (и «С инвестиций», если выводили). Больше 8 категорий — остальное в «Прочее». По умолчанию — прошлый полный месяц.
