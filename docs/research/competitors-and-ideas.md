# Похожие приложения: что у них есть и что стоит добавить нам

Дата: 2026-10-20. Сравнение с планом в [mvp-features.md](../product/mvp-features.md): ниже только то, чего в плане **нет**, с указанием, в какую версию это лучше положить.

Как собрано: обзоры, документация и каталоги в открытом доступе (ссылки внизу) плюс общее знание об этих продуктах. Сами приложения не устанавливались, поэтому детали функций конкурентов стоит считать ориентиром, а не точной спецификацией.

## Кого смотрели

| Приложение | Платформа | Чем известно |
|---|---|---|
| **Дзен-мани** | мобильное, веб | Загрузка операций из российских банков, чеки по QR, траты относительно среднего, прогнозы, недельная сводка в Telegram |
| **CoinKeeper** | мобильное | Наглядный ввод «перетащи монетку», семейный доступ, бюджеты, ввод голосом и по фото |
| **Дребеденьги** | веб, мобильное | Импорт по QR-коду чека, SMS, планирование |
| **Домашняя бухгалтерия (Keepsoft)** | Windows + телефон | Ближайший аналог по формату: ПК-программа, кредиты, долги, вклады, чеки по QR |
| **YNAB** | веб, мобильное | Бюджет «каждому рублю своя задача» (нулевой баланс), ритуал распределения денег |
| **Monarch Money** | веб, мобильное | Гибкий бюджет (фиксированные / гибкие / нерегулярные), диаграмма потока денег, цели, календарь регулярных платежей |
| **Copilot Money** | macOS, iOS | Очень вылизанный интерфейс, автоопределение подписок |
| **Actual Budget** | ПК (open source, локально) | Конверты, правила для получателей, расписания, сверка, арифметика в полях суммы, отмена действий |
| **Firefly III** | самохостинг | «Копилки» под цель, счета к оплате, правила, двойная запись |
| **GnuCash, HomeBank, Moneydance** | ПК | Классический учёт: сверка с выпиской, отчёты, ручной контроль |
| **MoneyWiz, Banktivity** | ПК + мобильное | Календарь будущих платежей с прогнозом на любую дату, отчёт о чистых активах во времени |
| **Money Lover, Spendee, Wallet** | мобильное | Шаблоны операций, «бюджет на день», события и поездки |

**Вывод по рынку.** Российские приложения почти все мобильные и облачные, с подпиской. Нормальной современной программы для ПК с локальными данными, российской спецификой и сильным разделом кредитов почти нет: Keepsoft старый и с жалобами на лицензирование, западные ПК-программы не знают российских банков, чеков ФНС и налоговых вычетов. Это и есть наша ниша, и рекомендации ниже её усиливают.

## Рекомендации

Обозначения версий как в плане: **MVP**, **v2**, **v3**. Звёздочка ★ отмечает фишки, которых нет у большинства конкурентов и которые могут стать «лицом» приложения.

## Что я бы добавил в первую очередь

**В MVP (всё дешёвое, на уже существующих данных):**

1. Арифметика в поле суммы и горячие клавиши (п. 1, 2).
2. «Можно тратить сегодня» на главном экране (п. 8).
3. Поле «Получатель» с подстановкой категории (п. 5).
4. Автокопия в выбранную папку (п. 27).
5. Тип счёта «кредитная карта» (п. 22, только тип).
6. Норма сбережений в сводке (п. 15), шаблоны операций (п. 4), отмена действий (п. 3), «скрыть суммы» (п. 7).
7. Календарь с тратами по дням и платежами по долгам, свои напоминания с окном «Сегодня» при запуске и уведомлением Windows, заметки к счёту, долгу и месяцу (п. 31–35). Напоминания о платежах по долгам при этом переезжают из v2 в MVP.

**Главные фишки для v2**, которые выделят приложение среди российских конкурентов: налоговый вычет (п. 21), кредитки с грейсом и вклады с калькулятором (п. 22, 23), календарь платежей (п. 12), диаграмма потока денег (п. 17), гибкий бюджет с нерегулярными тратами (п. 10, 11).

Решать, что из этого брать в план, владельцу; файл с планом функций [mvp-features.md](../product/mvp-features.md) этим отчётом не менялся.

### Что стоит передвинуть в уже существующем плане

- **Правила автокатегоризации (сейчас v3) → в v2 вместе с импортом выписок.** Без правил каждая импортированная операция Сбера требует ручного выбора категории, и импорт превращается в работу. Получатель с подстановкой категории уже есть, правила будут его продолжением.
- **Прогноз остатка на конец месяца (сейчас v3) → в ближайшее обновление.** Это одна строка под «Можно тратить сегодня» («при текущем темпе к 31-му останется 4 200 ₽»), считается из тех же данных.

### Что я бы взял первым

Пять дешёвых пунктов, которые сразу видны и не требуют настройки: **39** бюджет по среднему, **40** финансовая подушка, **46** мастер первого запуска, **42** курсовая разница и прогноз на конец месяца (из блока выше). Следом два «лица» ПК-версии: **37** быстрый ввод по глобальной клавише и **38** ввод одной строкой. Выбор за владельцем; план функций в [mvp-features.md](../product/mvp-features.md) этим разделом не менялся.
