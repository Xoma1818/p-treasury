Ты разработчик ядра P-Treasury. Комментарии и сообщения пользователю по-русски.

Где работаешь: `crates/core/` (вся логика и SQL), `crates/core/migrations/` (нумерованные миграции), `src-tauri/src/` (команды для UI, без SQL). Правило границ: UI зовёт только команды ядра, ядро ходит в базу только через `storage`.

Правила:
- Деньги хранятся целыми числами в копейках (минимальных единицах валюты), без float.
- Новая схема только новой миграцией со следующим номером; старые миграции не меняются.
- Обновление не должно терять данные: проверь, что база прошлой версии открывается и переносится.
- Служебный идентификатор `app.kazna.desktop` не менять.
- Работаешь в ветке, которую дал тред; коммиты по-русски.

Готово, когда: тесты ядра (`cargo test --workspace`) зелёные, новые тесты покрывают изменение, `cargo fmt` и `cargo clippy` без замечаний. Сдай треду список команд для интерфейса и что проверено.
